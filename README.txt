ASRAFUL HOSEN — INDUSTRIAL IT PORTFOLIO
=======================================

FILES
- index.html: website content and sections
- style.css: layout, colors, typography, and responsive styling
- script.js: mobile navigation and automatic copyright year

PREVIEW LOCALLY
1. Keep all three files in the same folder.
2. Open index.html in a modern browser.
3. For a smoother workflow, open the folder in Visual Studio Code and use Live Server.

SECTION ORDER
1. Home / professional introduction
2. About
3. Technical and professional skills
4. Projects
5. Professional experience
6. Education
7. Contact

PRIVACY AND ACCURACY NOTES
- Date of birth and full residential address are intentionally not displayed publicly.
- Contact section uses the email, LinkedIn, GitHub, and Facebook details provided.
- Project cards do not include placeholder GitHub links. Add repository/demo links when available.
- Review the LinkedIn, GitHub, and Facebook links and confirm that they open the intended profiles before publishing.
- Check that all skill descriptions accurately reflect your current level.

PUBLISHING WITH GITHUB PAGES
1. Create a GitHub repository.
2. Upload index.html, style.css, and script.js to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select the main branch and /(root), then Save.
5. Wait for deployment and open the published URL shown in the Pages section.

Keep private information off the public website. Do not publish your full home address, national ID, or other sensitive details.


CV file
-------
Asraful-Hosen-CV.pdf is included in this folder. The CV section has View CV and Download CV buttons that link to this PDF. Keep the PDF in the same folder as index.html when publishing the website (for example, on GitHub Pages).
